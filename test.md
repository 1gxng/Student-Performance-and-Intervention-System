# Validation Tests

The following tests were carried out against the Student Performance Worksheet Software. The tests cover normal, invalid, boundary, search, and menu-control behaviour as required.

| Test                                    | Input or condition                                                                                | Expected result                                                                                  | Actual result                                                                                                                                                                    | Status   |
| --------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| **Normal**                              | Valid record: `ST004`, programme `MSc IT`, marks `73, 76, 82`, attendance `82`, project submitted | Record should be accepted and processed successfully. Final mark should be `79.0` and grade `A`. | `ST004` is accepted as valid. Final mark is calculated as `79.0` and classified as grade `A`.                                                                                    | **Pass** |
| **Invalid – Missing value**             | Record with `cat_mark = None`, such as `ST005`                                                    | Record should be rejected with a reason indicating that CAT mark is not numeric.                 | `ST005` is placed in the invalid-record list with reason `cat_mark is not numeric`.                                                                                              | **Pass** |
| **Invalid – Out of range**              | Record `ST012` has `exam_mark = 108`                                                              | Record should be rejected because marks must be between `0` and `100`.                           | `ST012` is rejected with reason `exam_mark out of range (0-100)`.                                                                                                                | **Pass** |
| **Boundary**                            | A mark/attendance value exactly equal to `0` or `100`, and a final mark exactly `70`              | Values `0` and `100` should be accepted. A final mark of exactly `70` should receive grade `A`.  | Validation accepts values of `0` and `100`. The grading condition `final_mark >= 70` assigns exactly `70` to grade `A`.                                                          | **Pass** |
| **Search**                              | Search for existing student `001`, then non-existing student `999`                                | `001` should return `ST001`; `999` should display `Student not found`.                           | `001` is formatted as `ST001` and the student details are displayed. `999` produces `Student not found`.                                                                         | **Pass** |
| **Menu – Invalid option**               | Enter menu option `9`                                                                             | System should reject the option and display `Invalid selection.` while keeping the menu active.  | The program displays `Invalid selection.` and returns to the menu.                                                                                                               | **Pass** |
| **Menu – Exit**                         | Enter menu option `6`                                                                             | Program should display `Program closed.` and terminate.                                          | The program displays `Program closed.` and exits the `while` loop.                                                                                                               | **Pass** |
